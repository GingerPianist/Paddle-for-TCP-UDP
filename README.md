# The network-based Paddle game for showing the difference between UDP and TCP protocols
Hello! Welcome to our University Project, more coming soon!
# How to start?
1. Clone this repository using
`gir clone git@github.com:GingerPianist/Paddle-for-TCP-UDP.git`
2. Create and start the virtual environment by installing the requirements.txt file
3. Start the serwer.py and the klient.py
